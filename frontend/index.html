Deep Learning Model Architecture & Actual Performance

Complete technical documentation, mathematical formulations, training loss curves, and confusion matrix.

Multi-Branch Cognitive Neural Network (DeepCognitiveNet)

Designed specifically to solve the limitations of mark-based scoring. The model fuses two parallel representations:

Branch 1

Sequential Cognitive Bi-GRU with Self-Attention

Processes chronological question attempts. Encodes response dynamics: concept embeddings (16d), tier embeddings (8d), misconception distractor tags (8d), response latency, and confidence levels using a 2-layer Bidirectional GRU with self-attention pooling.

Branch 2

Structured Cognitive Profile ANN (Dense MLP)

Computes holistic behavioral metrics: overall accuracy, basic tier accuracy, conceptual accuracy, application accuracy, Tier Divergence (Basic - Application), average confidence, and error streak length.

Heads

Multi-Task Output Heads

1. Cognitive State Head: 4-class Softmax (Genuine Mastery, False Mastery, Misconception, Knowledge Gap)
2. Misconception Category Head: Multi-class distractor classifier
3. Prerequisite Risk Head: Continuous vulnerability regression [0.0 - 1.0]

Core Cognitive Diagnostic Insights

  • Why not just use marks? A student with 66% score can either have partial mastery or severe false mastery (memorized definitions, failed all practical applications). Our Deep Learning model identifies the difference.
  • How is False Mastery detected? Through the structured tier divergence feature vector fused with sequential hesitancy embeddings. High basic accuracy + low application accuracy triggers False Mastery classification.
  • How are Misconceptions detected? Question distractors are tagged with specific cognitive misconception codes. The multi-task neural network identifies consistent error patterns.
